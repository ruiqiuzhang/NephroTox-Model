# Supplementary workbook crosswalk

Worksheet names refer to the separate `NephroTox_Supplementary_Data.xlsx` used for verification. All modeling commands read the [compound CSV](source/data/NephroTox_Modeling_Data.csv). The [input provenance record](source/data/input_provenance.json) links its 1,673 ordered records to the archived run. Model IDs such as `maccs166__rf` are identical in the frozen registry, predictions and workbook headers.

| Worksheet | Original input, protocol or output | How to join or interpret |
|---|---|---|
| Data1 Modeling Dataset | `source/data/NephroTox_Modeling_Data.csv`; `reference/modeling_data.csv`; `reference/split_assignments.csv`; `reference/split_payload.json` | The first twelve columns are the input CSV fields, in the same order. The final three give the partition, validation fold and structure-group ID. Join on compound ID. Held-out rows have a blank validation fold. |
| Data4 OOF Probabilities; Data5 Test Probabilities | `reference/modeling/reports/oof_predictions.csv`; `reference/modeling/reports/test_predictions.csv` | Pivot the long-form probability field by compound ID and model ID. There are 1,338 out-of-fold and 335 held-out rows per model. Raw arrays in input order, including seed-specific outputs where applicable, are in `reference/modeling/<model_id>/predictions.npz`. |
| TableS1A Candidate Design | `source/configs/model_candidate_parameters.csv`; `source/configs/model_search_spaces.json`; candidate design fields in `reference/modeling/protocol.json` | The 180 candidate entries describe the available design across 43 model IDs. No candidate search was executed in the reported run. |
| TableS1B Fixed Models; TableS1C Fit Parameters | `source/configs/original_fixed_parameters.json`; `reference/modeling/protocol.json`; `reference/modeling/<model_id>/configuration_lock.json`; per-fit `fit_metadata.json` | S1B lists 43 fixed configurations. S1C records the configuration and controls of 473 fits (ten outer folds plus the full development set for each model). Fold-dependent execution seeds are recorded separately from the candidate designs. |
| TableS2A Graph Configs; TableS2B Graph Features | `source/configs/graph_feature_schema.json`; `source/src/nephrotox/modeling_graph.py`; `reference/modeling/graph__<architecture>/final_fit/fit_metadata.json` | Read the atom and bond vocabularies in their stored order. The worksheet uses zero-based column indices within each feature family. The implementation uses RDKit and CPU PyTorch, including stereochemical and directed-bond definitions. |
| TableS3A Fold Metrics; TableS3B Calibration | `reference/modeling/reports/perfold_metrics.csv`; `reference/modeling/reports/calibration_bins.csv` | Join fold metrics by model ID and outer fold. Probability calibration bins use the corresponding model ID, partition, and bin. |
| TableS4A Graph Performance; TableS4B Paired AUC | `reference/modeling/reports/model_summary.csv`; `reference/modeling/reports/paired_auc.csv` | Filter by graph model ID for S4A. S4B reports the specified model pair and partition. |
| TableS7A Conventional; TableS7B All Performance | `reference/modeling/reports/model_summary.csv`; `reference/modeling/reports/primary_selection.json` | Join aggregate metrics by model ID and partition. The selection record identifies the primary conventional model and the unweighted ten-fold selection criterion. |
| TableS7C Binary Count | `validation/paired_binary_count.csv`; `source/scripts/export_binary_count_tables.py` | Join by binary model ID, count model ID and partition. The file contains 15 matched pairs per partition, with count-minus-binary differences, paired bootstrap intervals and Holm-adjusted p-values. |
| TableS8C Inference Repeats; TableS8D Feature Repeats | `reference/modeling/benchmarks/runtime_measurements.csv`; `reference/modeling/benchmarks/feature_measurements.csv`; `reference/modeling/model_lock.json`; `reference/features/` | S8C identifies the original final model file by SHA-256. S8D records hashes of numeric feature matrices; these differ from hashes of the compressed NPZ containers. |
| TableS9A Selected Epochs; TableS9B Neural Curves | `reference/modeling/<model_id>/outer_<NN>/refit/fit_metadata.json`; `reference/modeling/<model_id>/final_fit/fit_metadata.json` | S9A lists the fit-metadata path relative to `reference/modeling` and its SHA-256. There are 121 neural fit records with three seeds each. Join the curves by model ID, scope, seed, epoch and stage. |

The numerical benchmark outputs can be inspected directly from the CSV and JSON files. Source datasets for unrelated chemical annotation and other non-modeling worksheets remain in the separately distributed supplementary workbook.
