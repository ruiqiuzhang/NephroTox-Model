# Figure typography

All main figures and supplementary figures must use Arial, including titles,
panel letters, axes, ticks, legends, tables and molecular atom text. This is an
explicit user requirement for Figure 1, Figure 2 and every subsequent figure.
Use configs/figure_style.json and scripts/figure_style.py. Do not silently fall
back to another font. Font-only changes must preserve the validated data,
partitions, representative compounds and layout.
